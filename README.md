# mauricioc24.github.io

Portfolio of **Mauricio Calderón Barrientos**, Data & AI Automation Analyst in Burlington, Ontario.
Live at **https://mauricioc24.github.io**.

- Plain HTML, CSS and JavaScript, served by GitHub Pages from `main`. No build step.
- Project and Quest Log content lives in `projects.json`; every fact comes from `CONTENT.md`.
- Look and feel follow `brand/BRAND.md`; motion and polish follow Emil Kowalski's skills in `.claude/skills`.

**Preview locally:** run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

**More:** [LEARNINGS.md](LEARNINGS.md) explains how it all works, [TODO.md](TODO.md) lists what's still missing, and [CLAUDE.md](CLAUDE.md) holds the rules for AI-assisted changes.
